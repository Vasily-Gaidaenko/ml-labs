# Классификация астрофизических источников 3FGL

Проект посвящён бинарной классификации блазаров и пульсаров по данным каталога Fermi LAT. Цель - сравнить несколько способов обработки признаков и оценить качество обнаружения пульсаров при дисбалансе классов.

## Данные

Исходный каталог содержит 3034 объекта. После отбора нужных классов осталось 1884 объекта:
- 1717 блазаров;
- 167 пульсаров.

Для классификации используются 28 числовых признаков. Данные разделены на обучающую, валидационную и тестовую выборки с сохранением пропорций классов.

## Методы

В качестве основной модели использовано дерево решений. Сравнивались следующие варианты:
- обучение на исходных признаках;
- применение PCA;
- PCA с oversampling пульсаров;
- отбор признаков по важностям дерева.

Дополнительно использован DummyClassifier для оценки базового уровня качества. Преобразования обучались только на train, а выбор итогового варианта проводился по F1 пульсаров на validation.

## Результаты

По результатам сравнения на validation выбрано дерево решений, использующее два признака — Par9 и Par26. Его метрики на test приведены ниже.

| Метрика на test | Значение |
|---|---:|
| Accuracy | 0.9753 |
| Precision пульсаров | 0.8913 |
| Recall пульсаров | 0.8200 |
| F1 пульсаров | 0.8542 |

Модель обнаружила 41 из 50 пульсаров в тестовой выборке.



Результаты получены на одном разбиении данных и могут изменяться при другом составе выборок.
