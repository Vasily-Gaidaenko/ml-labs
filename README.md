# Проекты по машинному обучению

Два учебных проекта: классификация табличных данных и исследование сверточных нейросетей.

## 1. Классификация источников 3FGL
Классификация блазаров и пульсаров с помощью дерева решений. Сравниваются PCA, oversampling и отбор признаков. Качество оценивается с учётом дисбаланса классов.

## 2. Устойчивость CNN к сдвигам
Сравнение двух архитектур CNN на MNIST. Исследуется влияние аугментации и сдвигов изображений на точность классификации. Реализация на PyTorch.
